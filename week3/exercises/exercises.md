Pedersenコミットメントの多項式への応用。

まず、信頼されたTrusted Setupの段階で、公開パラメータ（SRS）に新たな生成元h∈G_1を追加。このhは、既存の生成元g1との関係性（g1を何倍すればhになるか）が誰にも分からないように選ばれる。

証明者は、多項式f(x)にコミットする際、まず有限体F_pからランダムな値rを選ぶ。そして、コミットメントをCom_f := f(τ)⋅g1 + r⋅hのように、r⋅hを加えて計算する。このr⋅hの項を追加することで、コミットメントの値がランダム化される。

こうすると、同じ多項式f(x)にコミットしても、rを選ぶたびに全く異なるコミットメント値が生成されるようになる結果、コミットメント値Com_fから元の多項式f(X)に関する情報を割り出すことが不可能になり、秘匿性が実現する。

(1)算術回路の作成
まず、関数を基本的な演算（ゲート）の連続に分解。
ゲート0: v₁ = a * b (乗算ゲート)
ゲート1: v₂ = v₁ - a (減算ゲート)
ゲート2: v₃ = 5 * v₂ (定数との乗算ゲート)
ゲート3: v₄ = 2 * b (定数との乗算ゲート)
ゲート4: out = v₃ + v₄ (加算ゲート)

(2)ウィットネス（Witness）の割り当て
a = 2, b = 3 (ウィットネス)とし、各ゲートのワイヤーの値を計算。
ゲート0: v₁ = 2 * 3 = 6
ゲート1: v₂ = 6 - 2 = 4
ゲート2: v₃ = 5 * 4 = 20
ゲート3: v₄ = 2 * 3 = 6
ゲート4: out = 20 + 6 = 26
各ゲートの左入力 (L)、右入力 (R)、出力 (O) の値のベクトルを得る。

ゲート	(L,R,O)
0	(a=2,b=3,v₁=6)

ここから、セレクター多項式の元となる5つのベクトルqL, qR, qM, qO, qCが定義される。

4. 
複数のパブリックインプット制約を1つのKZG評価証明で効率的に検証するには、消滅多項式（vanishing polynomial）を用いたゼロテスト（zero testing）の手法を使う。

まず、k個のパブリックインプットがある場合、それぞれは特定の位置（インデックス）i（評価点ω^iに対応）で値vを取る、という形で定義する。例えば「ゲート#0の左入力は2である」といった制約になる。

次に、検証者は全てのパブリックインプットの値と位置を補間して、パブリックインプット多項式PI(X)を作成する（これは公開される）。

証明者は、自身のウィットネス多項式（例: L(X)）が、全てのパブリックインプットの位置でPI(X)と一致すること、すなわちL(X) - PI(X)が全てのパブリックインプットの位置でゼロになることを示す必要がある。

このために、全てのパブリックインプットの位置（i₁, i₂, ... i_k）を根に持つ消滅多項式Z_PI(X)を定義する。
Z_PI(X) = (X - ω^i₁)(X - ω^i₂)...(X - ω^i_k)

L(X) - PI(X)がこれらの点でゼロになるなら、L(X) - PI(X)はZ_PI(X)で割り切れる。証明者はこの割り算を行い、商多項式q(X)を計算する。
q(X) = (L(X) - PI(X)) / Z_PI(X)

検証時には、検証者はランダムな評価点rを選び、L(r), PI(r), q(r)の値とそれぞれの評価証明を証明者に要求する。そして、次の等式が成り立つかを一度だけチェックする（コミットメントに対するペアリングチェック）:
L(r) - PI(r) = q(r) ⋅ Z_PI(r)

シュワルツ・ジッペルの補題により、この単一のチェックが成功すれば、非常に高い確率で全てのパブリックインプット制約が満たされていることが保証される。これにより、検証が大幅に効率化される。
